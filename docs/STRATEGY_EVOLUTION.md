# 策略版本与改进

版本身份由策略 ID、版本号、实现摘要和参数摘要共同确定。运行时固定版本。更新代码和参数后建立新账户，新旧版本使用同一预注册区间收集数据。历史信号保留原版本、盘口和证据。

亏损先记录可核验事实，例如手续费、实际深度、滑点及单腿成交。关于价格反转、样本偏差和模型失效的解释作为待验证假设。无法决定原因时使用 UNKNOWN。改进建议应包含样本范围、证据链接、验证计划、风险、验收标准和人工审核状态。

Champion 为人工建立的研究基线。Challenger 须在独立的样本外和实时模拟实验达标后由人工审核。短期高收益和开发完成不会自动改变研究状态。回退时创建针对旧版本的新运行，并保留所有比较记录。

每天检查同版本、同原因反复出现的熔断，生成含风险流水编号的待审核建议。版本的执行参数不可变。比对时验证同实现、数据摘要、期间、虚拟本金、成本外参数、加费倍数与预注册时间；保留完整压力回放以及独立执行过的人工复核。样本充足性按研究协议计算。只有通过的评估能够人工晋级，旧版进 RETIRED，保留历史；回滚同样登记一次基线变更。
