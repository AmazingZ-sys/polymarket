# 策略研究注册表

| 策略 | 输入与输出 | 允许动作 |
|---|---|---|
| S00 | 记录不交易基准与可用的 UP 盘口概率 | 观察 |
| S01 | 配对同一市场 UP、DOWN，计算每腿深度、费用、限价、剩余时间和有效性 | 条件满足时独立发出两笔模拟 IOC |
| S02 | 按剩余秒数分组记录价格及规则、基准价和官方 Oracle 覆盖 | 尾盘观测，缺少结算输入时标记证据不足 |
| S03 | 记录可观察盘口市场概率，待实际结算后计算概率评分 | 概率校准研究 |
| S04 | 同资产不同周期、相邻基准价及同时观测概率的可比性 | 相关性研究 |

策略参数与代码实现版本绑定。每笔信号附可重建输入和解释。S01 的互补兑付依赖相同条件和正常二元结算。每腿的实际模拟成交以及最终资金变化单独保存。所有研究型策略可以持续处于无交易状态。

TWAP 由该市场版本的官方规则决定。样本缺失或窗口两端缺乏有效的原始观测时保留缺口。S02 的窗口参数控制分析时段，不能修改官方结算窗口。S03 用可验证结算标签对市场概率计算 Brier、Log Loss、分箱可靠性及 ECE，并披露样本数与重复市场的影响。
