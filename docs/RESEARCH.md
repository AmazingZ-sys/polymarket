# 研究协议

计量单位为已结算市场；一个市场两侧成交、重叠 5m / 15m 窗口和同期 BTC / ETH 不独立。先注册假设、成本、风险限额、有效样本定义、分割日期与停止规则。按市场结束时间分组，在训练与验证边界剔除跨界标签，并预留 embargo；重复尝试纳入多重检验记录。

以 S00 的零持仓和市场概率为对照。比较尾盘与全周期。保留弃权、拒单、单腿成交、亏损、缺口及异常结算。报告成交净值时单列已实现、可估值的未实现和运行费用。价格、权益或样本未验证时填写 N/A。

原始协议门槛为至少 90 天覆盖、1000 笔样本外有效成交、连续 30 天实时模拟、PF > 1.3、最大回撤 ≤ 5%、成本增加 50% 后净收益仍为正、区块自助法所得期望收益 95% 下界 > 0。还应检查延迟压力、极端单笔依赖、相关样本、数据质量及规则分层。通过全部预注册条件并经人工复核才能更改验证结论。数据积累中，当前无盈利证据。
