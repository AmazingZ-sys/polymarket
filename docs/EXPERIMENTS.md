# 独立对照实验

账户创建时固定研究假设、策略版本、参数、市场范围、费用与模拟模型。保存 JSON 配置与哈希。参数变化通过克隆建立新实验，重新初始化虚拟资金。不同账户观察同一档深度时各自做一次反事实模拟，多个账户的结果不可加总为可执行规模。

比较应固定共同研究时段、初始资金、资产、周期、结算规则、深度可用性与成本口径。披露未成交、部分成交、未结算、数据中断以及无信号的时段。盈亏率、回撤、费用、欠缺的标签和成交数一起报告。无有效结算的胜率和净期望显示 N/A。

预注册研究期及停止标准，保留负结果。盈利验证需要至少 90 天历史、1000 笔样本外有效成交和 30 天连续实时模拟，另须满足成本压力、回撤、区间估计、多重检验与独立人工审核等条件。当前状态为样本积累阶段。
