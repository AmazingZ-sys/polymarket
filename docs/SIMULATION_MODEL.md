# 撮合与成本假设

仅模拟带限价的吃单买入和持有至结算。每个信号保留接收时间、两个盘口 ID、规则版本、策略版本和每档报价。每条腿独立冻结资金。在预定延迟后检查到达时已可观察的同方向更新，按价格从低到高逐档成交。限价、截止时间、剩余深度和账户预算限制成交。缺少到达时证据时撤单解冻并记 UNVERIFIABLE。部分成交的剩余数量在本次 IOC 匹配结束时取消。

模型 basic-v1、conservative-v1 和 stress-v1 各自冻结延迟、可参与深度比例和价格冲击假设。深度折扣和额外滑点只计一次。没有排队证据的 Maker 单不计入模拟成交。成本以 Decimal 计算，手续费版本来自对应行情快照。费用单独记账，实际买入成本已经包含价差与模拟滑点。模拟费用以 USD 等价计入现金支出，未经验证的返佣计零。

按每档成交量乘费率及价格因子 p × (1 − p) 估算费用，来源参数缺失时拒绝模拟。该口径是成本模型，持仓股数采用模拟支付现金费用的约定。核查日期 2026-11-26。[Polymarket 费用公式](https://docs.polymarket.com/trading/fees)
