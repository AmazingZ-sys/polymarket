# 单机备份、更新、回滚和恢复演练

2026-11-26 UTC。使用单独的 Compose 项目、新密码、新 PostgreSQL 数据卷、新 Parquet 数据卷和随机宿主机端口。测试使用本机已有镜像、隔离虚拟账户及该项目采集的数据。

| 运行 | 实测结果 |
| --- | --- |
| 初始化 | Compose migrate 正常退出，API/Web 就绪。创建 1,234.56780000 USD 虚拟账户，初始资金对应一条流水。 |
| 在线备份 | 成功创建 8.6 MiB PostgreSQL 自定义格式转储和 5.7 MiB 压缩归档包，清单包含 10 个 Parquet 文件、49,586 条历史事件。 |
| 隔离恢复 | 10 个文件均通过数据库清单 SHA-256 检验。新库账户可用余额和流水可用变动之和均为 1,234.56780000 USD，流水数为 1。恢复命令同时验证流水连续性。 |
| 完整性负例 | 复制转储、用空 Parquet 包替换原包并重算外层摘要。恢复命令根据转储内的文件清单拒绝缺失文件。 |
| 升级与手动回滚 | 使用同一应用镜像的两个本地演练版本标签执行更新，临时库迁移和账本检查通过。目标服务就绪。执行 rollback 后原版本就绪，账户和历史保留。 |
| 更新运行失败 | 对测试候选 Web 使用不能提供 Web 服务的本地镜像。候选未通过就绪检查，update 命令返回非零并自动恢复上一个已验证的应用版本。随后 healthcheck 返回 ready，虚拟账户和初始流水均核对通过。 |
| 不兼容迁移预演 | 派生测试 Worker 镜像，在临时库成功运行测试迁移。缺少对应版本的迁移兼容记录时，更新提前退出；查询运行库确认测试表不存在。 |
| 缺失回滚镜像 | 将隔离环境中的回滚点暂时指向本机不存在的版本。回滚返回非零，原服务仍就绪且版本未变。随后还原演练检查点。 |

测试版本标签仅用于本地演练。GHCR 发布、跨机迁移、域名及 HTTPS 由单独的发布与部署验证覆盖。没有产生研究盈利结论。
