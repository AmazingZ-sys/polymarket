# 风控与恢复

模型在信号前、订单到达时、权益变动后分别执行检查。默认单次机会合计冻结额度最多为可估权益的 0.5%，单日权益损失阈值 2%，峰值回撤阈值 5%。未平仓时使用可观察买价估值；缺少可用买价时停止加仓并保留估值状态。拒绝杠杆和自动加码。

市场缺少已验证规则、双边盘口时间不一致、费用未知、过期或越过交易截止时间时放弃交易。单市场、单资产及组合风险使用成本敞口计算，关联资产按总敞口保守聚合。规则变更、行情中断或账务不平触发事件，取消未成交委托。停机期间的盘口不进入补成交。恢复由管理员发起，后续仍须有新鲜、完整且规则通过验证的行情才可触发策略。

核对可用与冻结流水合计、冻结额对应开放订单、虚拟持仓对应成交与结算。REJECTED、EXPIRED 和零成交样本均计入研究记录。
