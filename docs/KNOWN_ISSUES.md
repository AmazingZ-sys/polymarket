# 已知问题

- 国际站实盘仅接入 Deposit Wallet 的独立 CLOB Session Key 和 S01 双腿买入。单腿暴露、回报丢失或上游交易未最终确认时，账户页显示待对账。若请求超时且没有持久化的委托号，执行器无法自动匹配该请求，保留本金占用并停止该钱包后续下单。
- 手续费按可归属的最终 Polygon 成交日志确认，公共 RPC 不可用时保留待确认状态。两条 FOK 委托独立撮合，双腿同时成交无法保证。真实资金成交不在自动化验收范围内。[实盘运行手册](LIVE.md)

- 当前无足量的真实样本外成交与连续运行样本。盈利能力处于 INSUFFICIENT_DATA。
- 行情、许可和外部依赖随时间及部署地区变化。逐源探测结果见 DATA_SOURCES.md；空档不得以回填成交消除。

- 2026-11-26 的宿主机盘口抽样中，633 个 BOOK 只有 176 个通过采集质量门槛，来源至接收的延迟中位数约 7.83 秒、P95 约 21.29 秒。该窗口出现 22 次缺口。部署者应以自己的数据中心记录解释运行状态。
- 已核实的四个市场均使用特定 TWAP 流。受权的 PolyBolt 预言机缺少现场订阅凭证，其实际端到端可用性待部署方确认。外部参考价仅用于统计。S02 和 S04 主要输出观察结果。
- 无订单队列优先级数据，当前撮合实现以带延迟且按深度折扣的 taker IOC 为主。缺少可验证输入的场景弃权。策略晋级需要充足样本及人工审核。
- 真实 Telegram/Webhook 投递、目标服务器 HTTPS、Vercel 账户发布及长期无人值守可用性依赖部署现场。测试凭证与短时检查不构成这些项目的验证证据。
- 15 GiB 低磁盘 VM 剖面只适合短时间采集和小窗口回测。连续高频采集、长时间回放及本地长期留存需要更大的持久盘和机器外归档。
- 按需回测数据集接口当前只复查本机已经采集或导入的事件。历史上游接口仍受部署地区、权限和 403 访问限制影响，`DATA_UNAVAILABLE` 不会自动补抓或用插值填充。

- 部署包默认关闭常驻采集。15 GiB 是单盘使用目标，磁盘保护覆盖挂载的归档文件系统。镜像、数据库 WAL、备份和其他进程仍能写盘。
